# Plan Projet

Application web simple pour découper un projet en tâches (4 niveaux) et les planifier sur un diagramme de Gantt, inspirée de [GanttProject](https://www.ganttproject.biz/).

## Utilisation

Ouvrir `index.html` dans Chrome ou Edge (double-clic). Aucune installation nécessaire.
Les données sont enregistrées automatiquement dans le navigateur.
